## 📌 代表性项目
### 1. 基于2D CNN的AM/FM调制识别
一维信号经STFT转为频谱图，PyTorch搭建卷积网络；
数据集覆盖0~20dB信噪比，整体识别准确率99.5%，0dB下94.2%；
附带Flask可视化Web演示。

仓库：https://github.com/mimi077/CNN-AM-FM-Recognition

### 2. STK低轨卫星链路仿真与数据预处理
搭建STK+Python流水线，面向NTN星地链路；
TLE轨道推演、可见性计算、AER方位仰角数据清洗与时序可视化；
将轨道几何信息转化为信道增益、时延参数。

仓库：https://github.com/mimi077/leo-stk-link-dataset-preprocessing

### 3. 高速移动信道功率分配策略
基于Sionna复现3GPP TDL-C多普勒时变信道；
由KKT条件实现注水算法闭式解，和均匀分配对比增益约9.4%~10.8%。

仓库：https://github.com/mimi077/mobile-comm-power-allocation
